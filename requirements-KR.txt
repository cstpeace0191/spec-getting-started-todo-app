# ============================================================================
# 기능 설명 (Features)
# ============================================================================
#
# 1. 할 일 목록 조회 (Todo list view)
#    - 페이지 로드 시 GET /api/items 로 저장된 모든 할 일을 가져와 표시합니다.
#    - 할 일이 하나도 없으면 "No items yet! Add one above!" 안내 문구를 보여줍니다.
#    - 데이터를 불러오는 동안에는 "Loading..." 을 표시합니다.
#    - 관련 코드: client/src/components/TodoListCard.jsx,
#                 backend/src/routes/getItems.js
#
# 2. 할 일 추가 (Add item)
#    - 상단 입력창에 이름을 입력하고 "Add Item" 버튼을 누르면 POST /api/items 로 전송됩니다.
#    - 서버는 UUID v4 를 id 로 부여하고, completed 는 false 로 설정하여 저장합니다.
#    - 입력창이 비어 있으면 버튼이 비활성화됩니다. 전송 중에는 "Adding..." 으로 바뀝니다.
#    - 관련 코드: client/src/components/AddNewItemForm.jsx,
#                 backend/src/routes/addItem.js
#
# 3. 완료 상태 토글 (Toggle completion)
#    - 각 항목 왼쪽의 체크박스 아이콘을 누르면 PUT /api/items/:id 로
#      completed 값이 반전되어 저장됩니다.
#    - 완료된 항목은 "completed" 스타일(CSS 클래스)로 표시됩니다.
#    - 관련 코드: client/src/components/ItemDisplay.jsx,
#                 backend/src/routes/updateItem.js
#
# 4. 할 일 삭제 (Delete item)
#    - 각 항목 오른쪽의 휴지통 아이콘을 누르면 DELETE /api/items/:id 로 삭제됩니다.
#    - 관련 코드: client/src/components/ItemDisplay.jsx,
#                 backend/src/routes/deleteItem.js
#
# 5. 인사말 표시 (Greeting banner)
#    - 화면 상단에 GET /api/greeting 이 반환하는 "Hello world!" 제목을 표시합니다.
#    - 프론트엔드와 백엔드가 연결되어 있는지 확인하는 용도의 예제 기능입니다.
#    - 관련 코드: client/src/components/Greeting.jsx,
#                 backend/src/routes/getGreeting.js
#
# 6. 데이터 저장소 선택 (Persistence)
#    - MYSQL_HOST 환경 변수가 있으면 MySQL 에 저장합니다 (mysql2 사용).
#      서버 시작 시 todo_items 테이블을 자동 생성하고, DB 가 준비될 때까지 기다립니다.
#    - MYSQL_HOST 가 없으면 SQLite 파일에 저장합니다 (기본 경로 /etc/todos/todo.db,
#      SQLITE_DB_LOCATION 으로 변경 가능). 디렉터리가 없으면 자동으로 만듭니다.
#    - 관련 코드: backend/src/persistence/index.js, mysql.js, sqlite.js
#
# 7. 서버 종료 처리 (Graceful shutdown)
#    - SIGINT / SIGTERM / SIGUSR2(nodemon) 신호를 받으면 DB 연결을 닫고 종료합니다.
#    - 관련 코드: backend/src/index.js
#
# ----------------------------------------------------------------------------
# REST API 요약 (Summary of endpoints)
# ----------------------------------------------------------------------------
#   GET    /api/greeting      -> { greeting: "Hello world!" }
#   GET    /api/items         -> [ { id, name, completed }, ... ]
#   POST   /api/items         body: { name }          -> 생성된 항목 { id, name, completed:false }
#   PUT    /api/items/:id     body: { name, completed } -> 수정된 항목
#   DELETE /api/items/:id     -> 200 OK
#
# ----------------------------------------------------------------------------
# 기타 (Other behavior)
# ----------------------------------------------------------------------------
#   - 백엔드는 포트 3000 에서 실행되며, 빌드된 클라이언트 파일을 /static 에서 함께 제공합니다.
#   - 개발 환경(compose.yaml)에서는 Traefik 프록시가 http://localhost 의 /api 요청은
#     백엔드로, 나머지 요청은 Vite 개발 서버(포트 5173)로 전달합니다.
#   - phpMyAdmin 은 http://db.localhost 에서 MySQL 데이터를 직접 확인할 수 있게 합니다 (개발용).
#   - 현재 기능 범위: 로그인/사용자 구분 없음, 할 일 수정(이름 변경) UI 없음
#     (API 는 name 수정을 지원하지만 화면에는 노출되지 않음).
